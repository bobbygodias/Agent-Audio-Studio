# Models, plugins, and assets

Before using an optional model, VST/LV2 plugin, cabinet impulse response, SFZ/SoundFont, or sample pack:

1. Check whether it is already present and usable in the active runtime.
2. Identify its source, license, model-weight terms, redistribution limits, hardware and runtime needs.
3. Estimate download/storage/runtime cost. Ask the user before a large download, paid item, or unclear license.
4. Keep model/plugin identity and version in the processing recipe. Do not upload the user's audio to a third party without explicit direction.

Project source code license and pretrained-weight license can differ. A public GitHub repository is not by itself permission to redistribute weights, plugins, presets, or sample libraries. Prefer open, auditable components and preserve attribution notices.
